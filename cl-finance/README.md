# CL Finance — безопасная демонстрация

Открыть файл: [cl-finance/index.html](./index.html).

- Независимое от основного проекта «Геомаш» приложение.
- Только вымышленные исходные данные.
- Работает без сервера: данные сохраняются в localStorage конкретного браузера.
- Можно добавлять объекты, брони, расходы, менять сценарий и экспортировать JSON.
- Не использовать для реальных финансовых или персональных данных.
- Для GitHub Pages нужно включить Pages в настройках репозитория (Deploy from a branch, main, /root). После этого путь: https://p9fvtdvpwy-ops.github.io/Kds-test/cl-finance/
- Для производственной версии нужны сервер, база данных, авторизация, резервное копирование и контроль доступа.
